# Análise de Currículos com IA

Este projeto foi desenvolvido com **Next.js** em um modelo **full stack** e tem como objetivo demonstrar a integração entre Inteligência Artificial e uma aplicação web prática.

O sistema permite que o usuário insira os requisitos de uma vaga, adicione seu currículo (em texto ou arquivo PDF) e receba uma análise detalhada da aderência do seu perfil profissional, incluindo pontuação, pontos fortes, pontos a melhorar e recomendações personalizadas.
